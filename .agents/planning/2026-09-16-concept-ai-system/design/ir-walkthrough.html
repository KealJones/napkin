2 · The one shape

Everything is Head(args).

Every value, every thought, every line of code is written the same way: a capitalized head and its arguments.

Times(5, 3)
Film(1999, American(), Comedy())
Bind($x, 1.5)  ← that's code: const x = 1.5

A lowercase word on its own is not allowed. Pie() is a Concept; pie is nothing. $x is a hole a pattern can fill.

what it IS / what it DOES
3 · Concepts

A Concept is facts plus tricks.

Concept(Pie(),
  IsA(Food())  // a relation: what it is
)
Concept(Multiply(),
  Realization(Multiply(), context = Speaking(), body = "times")
) // a realization: what it does, and where

Relations are claims (IsA, SynonymOf...). Realizations are behaviour, each with a pattern, a context and a body. Everything learned carries a stamp saying where it came from, so it can be traced and deleted.

4 · Picking a move

Nobody dispatches. It climbs the family tree.

To run Plus(A(), B()), Napkin looks for a realization, starting with the word itself and climbing what it IsA, all the way up to the universal parent, Concept.

Plusits own tricks win
Infixthen its kind's
CodeWordthen its kind's kind
Conceptthe fallback everyone inherits

Ties break by: nearer beats farther, a more specific context beats a vaguer one, what worked before, then newest. If nothing matches, the call comes back as itself. That's a residual, and it's not an error (see scene 8).

5 · Context

Same word. Different room. Different move.

A context is a set of facets. A realization only runs in the contexts it names. Here is one Concept, Times, in five rooms, with no if-statements anywhere.

→ Times(5, 3)
hearing English: the word finds its numbers, it doesn't multiply

→ Times(A(), B())

Code(TypeScript()), Reading()

reading code into the IR

Mood is a facet too. "what is 17 times 4" reads as Mood(Interrogative(), What(Is(Times(17, 4)))), and Interrogative has one realization that every question word inherits.

7 · Code is just more words

A loop gets heard like a sentence.

Each token is its own word's Concept. The language is the context: Code(TypeScript()).

for(constelementofobject){print(element)}
↓sense: each word says what it is here (this { is a block, these brackets pair)
↓link: For takes its header and its block, Of joins two sides
For( Of(Const(Element()), Object()), Print(Element()) )
↓read under Context(Code(TypeScript()), Reading())
Module(ForOf($element, $object, Call($print, $element)))

Python says for element in object:, gets heard as For(In(...)), and reads to the exact same IR. Then To rules write it back out in any language. Intent in, any language out.

8 · Not knowing is useful

A residual means "look further".

When something evaluates to itself, Napkin doesn't guess. It goes looking, in this order:

what the graph holds what you told it behaviour the question names the world: Wikidata, Wiktionary, the web a model, last resort

Whatever it finds is kept with a stamp saying where it came from. And if it's truly stuck, it says so: Unknown beats a confident guess.

One shape. One climb. One room at a time.

Everything is Head(args). Behaviour comes from what a Concept is and the context it's in, never from dispatch. Hearing gives structure, working out gives meaning, and not knowing is a signal, not a failure.
