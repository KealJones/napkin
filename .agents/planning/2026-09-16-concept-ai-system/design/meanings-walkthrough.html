A side trip

One word.
Many meanings.

"Add" means sums, shopping lists, code and gossip. Napkin keeps them all, and never mixes them up. Here is every tool it has for that, one scroll each, with the one word Add.

scroll ↓
1 · The question

Which Add runs?

A Concept can have many realizations: ways it behaves. When Add(...) is evaluated, Napkin picks one. The trick is not writing clever code inside Add. It is saying, on each realization, when it is the one. There are eight ways to say that, and each answers a different question.

two things in, one out
2 · Shape

What was it given, in what shape?

Add($left, $right) → 8

"add 5 and 3" is heard as Add(5, 3). The pattern's shape (two things) is what matches.

Careful: hearing reads a doing's shapes to know how many things it takes. A new one-thing Add($x) in Execution() once made "add 5 and 3" come out Add(And(5, 3)). Shape is the most global choice there is.
3 · Types

Same shape. Different things.

types = Types(left = Number(), right = Number())
add 5 and 3 → 8
types = Types(a = Date(), b = Duration())
add 3 days to today → a date

Both are Add($a, $b), both in the same situation. Only what they are given differs, so the realization says what it wants. Pick one whose types fit; if they don't, the next one gets a turn.

same call, different room
4 · Context

Where is it asked, and how?

Execution()
Add(5, 3) → 8
Speaking()
Add → "plus"
Code(Python())
Add(a, b) → (a + b)
Interrogative()
"can you add cheetos to my list?" → done
Hypothetical()
"what if I add milk?" → says what would change, changes nothing

Same arguments, different situation: saying it, writing it in a language, being asked nicely, only supposing. That is context. Never check the mood inside a body; say it on the realization.

5 · The parent

What every doing of a shape does.

Add(List(3, 4, 5)) → 12

Nobody wrote an Add for a group. Every doing that takes two things gets "take a whole group, a pair at a time" on the universal parent, derived once. Add, Multiply, Max: all of them, and none lists it.

"not me, next!"
6 · Hand-over

It matched. Was it really for this?

add cheetos to my list→list-add: a list is named ✓
add 5 (after 4)→list-add: nothing named, hands it back→sum: 9

Some things can only be known by looking. A realization that finds it does not apply hands back the call it was given, and Add's next realization runs. If a type or a shape could have said it, use that instead.

7 · Names

Another name. Or several words, one thing.

Plus→SynonymOf(Add) "5 plus 3" is Add, in every meaning
add up→AddUp its own doing; the fold is derived from its name

A synonym is the same in every meaning. An alias only names it ("wife" names a spouse without being one), so aliases are Called(Wife()), never synonyms.

"...and bring snacks," she added
8 · A meaning that does nothing

Held, not run.

Add Relation(IsA(Saying()), context = Saying())

"Add" also means to say further. Nothing does that; it is just true of the word. So it is a fact in a context named by what that meaning is. A question in that context finds it; a sum never sees it. That is all "a sense" is: one meaning's facts, in its own context.

9 · Choosing

Ask these, in order.
