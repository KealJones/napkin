# Concept-centered AI: planning

Start with **`design/README.md`**. It says which documents are current, lists every known
divergence between the specs and the code, and records the findings that live in no spec.

```
rough-idea.md      the original vision, in the author's own words
idea-honing.md     the questions that shaped it, and the answers

design/            the specifications, and README.md saying which to trust
research/          measurements and literature, all current
legacy/            superseded, kept for the reasons in legacy/README.md
```

`rough-idea.md` and `idea-honing.md` are the origin documents and outrank everything else
on questions of intent. Where a spec and the author's stated intent disagree, the intent is
the requirement and the spec is the bug.
